## Project Description

Voice Optional is an inclusive festival concept that encourages communication beyond spoken language.

The main experience, **Match the Signs**, is a physical, screen-free matching game that introduces visitors to sign language through play.

## 1_Touchpoint

Contains the final Match the Signs game materials:

- Final playing cards — printable game materials.
- Game instructions — rules and explanation of the experience.
- Installation visuals — photos or mockups showing how the game works in the festival environment.
